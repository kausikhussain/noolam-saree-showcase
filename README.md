# NOOLAM · Kanchipuram Silk Saree Flagship

<p align="center">
  <img src="screenshots/01-hero.png" width="100%" alt="NOOLAM Hero Showroom">
</p>

> **NOOLAM** is a digital luxury flagship for heritage Kanchipuram silk sarees. Built with **Next.js 15**, **React 19**, and **Three.js** real-time cloth simulation, it features interactive 3D silk drape physics, an editorial luxury shopping cart, multi-currency pricing, and private video concierge consultation.

---

## ✦ Features & Interactions

- **3D Silk Curtain Intro**: Interactive silk-curtain simulation parting on entry with Three.js cloth physics.
- **Woven for the Divine (Hero)**: Glass-morphism floating navigation, showroom perspective, and continuous gold silk marquee ticker.
- **Six Moods (Gopuram Arches)**: Temple-arch architecture frames with lift-and-glow hover interactions.
- **Try the Look**: Dynamic drag/scroll carousel with real-time look inspector and -10% bundle checkout.
- **Pick a Silk**: 3D cursor-tilting silk cards on a gentle curve with immediate add-to-bag.
- **The Rack & Detail (3D Cloth)**: Real-time 3D garment physics on wooden hangers with front/back inspection and size selection.
- **The Muse Film & Reels**: 3D curved arc reel carousel with full-screen cinema viewer.
- **The Bridal Collection**: Muhurtham silks curated in arched gallery view.
- **Three Silks, One Weave**: Interactive 3D ribbon weave simulator.
- **Luxury E-Commerce Engine**:
  - Slide-over **Shopping Bag** with persistent local storage
  - Multi-currency switcher (INR ₹, USD $, GBP £, AED د.إ)
  - Automated promo codes (`NOOLAM10` for 10% off, `UTSAV` for ₹2,000 off)
  - Pincode serviceability & express delivery calculator
  - 3-step **Private Checkout** with instant order receipt generation
  - **Saved Heirlooms Wishlist** drawer
  - **1-on-1 Live Video Consultation** booking with WhatsApp Concierge

## ✦ Quick Start

```bash
# Clone the repository
git clone https://github.com/kausikhussain/noolam-saree-showcase.git
cd noolam-saree-showcase

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
